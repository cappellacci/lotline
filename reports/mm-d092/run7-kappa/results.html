Lotline · Missing middle · D-092 run 7, the baseline's own spread · 15 Nov 2026

A place's no-reform path is off by more than ×2 most of the time, so one spread number can't describe it

Runs 4–5 failed because each place's no-reform baseline was treated as certain. Run 7 measured how far baselines actually miss, on 483 places the fit and tests never use. The miss is so large (κ = 7.7) that a single gamma spread would forecast most places near zero. Two to four unit buildings arrive in projects, and a three-year baseline catches or misses a project by chance. The refit is on hold until the baseline itself is steadier.

For Ben

Steady the baseline before refitting

Using κ = 7.7 would pass test C only because the ranges would cover almost anything. The proposal: pre-register a few baseline constructions (six pre-years, the state's growth index instead of the place's own, no growth index, and a per-year negative binomial for project lumpiness) and score them on these same uncoded places. Then take the best one's κ into the refit. These places are never used by the fit or the §7 tests, so nothing leaks.

Run: scripts/dev/mm_kappa_d092.py, origins 2016 and 2021, five-year horizon, test C's baseline construction (own growth, 3 pre-years, zero floor), no reform term. Uncoded MN, NC, OH and TX places, minus test C's 11; no fit, test, level or holdout place. Cached tables only; nothing unblinded.
