Place types don't narrow missing middle's ranges

Giving core cities, suburbs and towns their own year-to-year lumpiness improved the held-out score by 24.8 log points, with a standard error of 32.9. The pre-registered bar was 2 standard errors, so one φ is kept and the refit isn't run. Coverage doesn't move (0.79 against 0.78). The size of the difference depends more on the state than on the type of place.

Finding 2

The state matters more than the type

φ by state and type (C core city, S suburb, T town). Within each state, suburbs are lumpier than towns. But Texas's core cities and suburbs both hit the search's upper limit (shown in brass), while the other states' sit at 3–12. A state term isn't a candidate, because it wouldn't carry to a state with no permit data.
