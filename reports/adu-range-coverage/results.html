Are the ADU ranges the right width?

Each state was left out in turn and every one of its 64 counted places predicted from the other states (A + place types, checked rule rows). We then asked where each place's actual count fell in its predicted range. If the ranges are honest, 80% of places land inside the middle 80%.

What makes a state's range wide

Removing each place's own unexplained rate shrinks a state's range the most: from about ×25 to ×5–9 in North Carolina, Texas and Oregon. Removing the unknown state level helps less (to ×15–20). The fitted parameters alone give only ×3–5. Minnesota's range is narrow because 43 places average their luck out.

"Inside P10–P90" flatters small counts, since a place with 0 built is inside any range that starts at 0; the randomized column corrects for that. The test D and D-091 rows use the plain percentile.

What this suggests

  • Don't narrow the ranges across the board. Over all places they are about right, a little narrow if anything.
  • Test a separate place-luck spread for core cities and suburbs. Core cities carry almost all ADUs and look too wide; suburbs look too narrow. Fitting one spread for each type would narrow the state totals honestly, if it holds up held out. It would need its own entry (D-094) before any fit.
  • The cheapest narrowing is data: counts for the biggest core cities. Where a city has its own counts, the engine already uses them (D-093), replacing that city's luck with what it actually built.
  • Over time, drift was the fix. Without it, forecasts of 2021–25 held about half the places in the middle 80%; with D-091's drift, which the engine now uses, about 80%.
