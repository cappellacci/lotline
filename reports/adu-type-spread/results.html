What this means

  • No change to the model. The held-out score is flat, so the narrower state ranges are not earned.
  • The fit's "core cities vary less" is a Minnesota suburbs story. Its 41 suburbs are very uneven; that inflates one shared spread. Without them, nothing says core cities are steadier.
  • Narrowing honestly still means more counted core cities. Sixteen core cities in four states cannot pin a separate spread; the data hunt for Texas, Ohio and Oregon sources is the route.
