What to know

  • m_x is fixed in a run. Its leave-one-state-out values run from 0.4 (without Oregon) to 1.0 (without North Carolina), so the result's range does not yet carry that uncertainty. At 1.0 a partial rule already counts in full and the bill adds nothing there; at 0.4 it adds 150%.
  • The rule fixes depend on PR #440. These runs read its rows; the config is on PR #437's branch and fits them, so #440 should merge first.
