### LB-NNN · 2026-10-19 · Build: pro forma (residual land value) for seven prototypes
- **Question:** Can the engine say whether a reform (more units, lower fees) makes building on a lot pay?
- **What I did:**
  - `src/lotline/model/proforma.py`: residual land value = finished value − hard − soft − fees − financing −
    profit, for ADU, single-family, duplex, triplex, fourplex, townhouse row and 5–6 unit building, for sale or
    rental (NOI / cap rate); commercial-code cost step at 3+ attached units with a triplex switch; feasibility
    against existing-use value × (1 + margin); land-capture λ helper; P10/P50/P90 over parameter ranges
    (triangular draws, fixed seed).
  - `config/params/proforma.yaml`: 25 parameters with ranges and sources (2025 dollars); weak sources say so.
  - `docs/analysis_plan.md` D-009: specification choices the research docs leave open.
- **Inputs:** methods review §2a; fees, MM causal diagrams; confounder register C40–C54; fees.yaml (λ, $50k).
- **Outputs:** `src/lotline/model/proforma.py`, `config/params/proforma.yaml`, `tests/model/test_proforma.py`,
  `docs/analysis_plan.md` (D-009).
- **Findings:** with central parameters, a $25k/unit fee cut raises residual land value by exactly $25k per unit
  when fees are paid at completion, or ~$26.6k (IRC) / ~$27.7k (IBC) including the interest saved when paid at
  permit; the code step alone costs a triplex ~$27k per unit.
  Code step, ADU premium, operating costs and existing-use margin have no solid public source (wide ranges).
- **Decisions:** D-009 accepted by Ben 2026-10-19 (profit on value; code step as a cost-per-sq-ft premium;
