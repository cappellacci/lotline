## LB-xxx · 2026-11-07 · WS-APP · State map on the results page

**Question answered:** How does a visitor see which states Lotline has run, how much local data each rests on, and what to do about a state it hasn't run (WS-APP brief: "A US map colors states by data tier; states without a bundle are grey with a 'bring your own state' link")?

**Outputs**
- `src/lotline/app/us_tiles.yaml`: a square tile grid of the 50 states and DC (code, name, row, column). It holds layout only, not which states were run.
- `src/lotline/app/build.py`: `tile_map()` validates the grid (no repeated code or cell) and maps data tier onto the identity's tier ramp (`TIER_TOKENS`: tier 1 → `--tier-5`, 2 → `--tier-3`, 3 → `--tier-1`; richer data is the stronger step). It reads the repo URL from `challenge.toml` for the grey-state link.
- `src/lotline/app/template.html`: the "Choose a state" card at the top of Results. Clicking a coloured tile switches state, grey tiles open the README's "Bring your own state" section, and bundles not on the grid (e.g. the fixture's `ZZ`) are listed as buttons. Changing `?state=` in the URL now switches the state too.
- `README.md`: a new "Bring your own state" section: config file, national fetch, optional local adapters, then `lotline results --state XX`.
- `tests/app/test_build.py`: four tests (grid complete and unique, repeated cell refused, tier tokens exist and are ordered, the README anchor exists, the map is on page 1).

**Choice:** a tile grid rather than drawn boundaries. It needs no new library or geometry download (the brief asks Ben before any CDN asset), it works offline like the rest of the page, and small states are as easy to click as large ones.

**What Claude did and how it was checked:** Claude Code (Opus 5.5, WS-APP instance) wrote the layout, code, README section and tests. Checked by `tests/app` and `compliance_check.py`, and in a browser with four synthetic bundles (tiers 1–3 plus an off-grid code): clicking tiles, the picker, the URL and the off-grid button all keep the selection in sync, at desktop and phone width, in light and dark mode, with no console errors.

**Follow-up (2026-11-08, Ben):** if every state is precomputed on national data, few or no states stay grey. The call to action therefore also sits on the tier-3 legend entry ("sharpen it with your state's own data"), and the grey entry shows only while a grey state remains. Same README section.
