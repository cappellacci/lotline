# Archived logbook fragments

These 411 fragments are the detailed, per-PR record of the work from 2026-10-19 to 2026-11-27. They were never
folded into `LOGBOOK.md` one by one. Instead, the nightly review summarized them there, about one entry per day
and topic (the entries marked *(auto-review)*, through LB-228). Most summaries name the PRs and branches they cover.

They are kept here, unchanged, as the full record behind those summaries. `scripts/dev/merge_logbook.py` reads
only `logbook.d/*.md`, so it ignores this folder.
