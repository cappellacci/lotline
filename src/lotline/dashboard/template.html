How these numbers are made
Population covered
Share of the 2020 population living in jurisdictions with at least one parcel on file. Unincorporated county areas take the county's 2020 estimate less the jurisdictions listed in it.
Parcels on file
Each jurisdiction's latest roll from one source. Where sources overlap, the source named in the state config wins; otherwise the largest. Counts are never added across sources.
Zoning code attached
Parcels whose record carries a zoning district. Where zoning is unknown the missing-middle rule assumes single-family-only zoning.
Eligible parcels
The model's denominators (eligible-parcel rule 1.1), latest year counted from a roll; ACS fallback where no roll exists.
Data tier
3 = national data only (BPS, ACS, FHFA); 2 = parcels with land use; 1 = parcels with land use and year built.
Housing units
ACS 5-year total housing units (B25024), labeled by the survey's end year, so each point averages five years and lags the permits line.
Population
Census Population Estimates (July 1). 2010–2019 from vintage 2020, 2020 on from vintage 2025; the 2020 seam changes the Census base.
2010 stock + permits
2010 ACS housing units plus every unit permitted since. It ignores demolitions and unbuilt permits, so it runs above the ACS line.
Holdouts
Built only from processed tables, which already exclude held-out outcomes (for example St. Paul permits from 2024 on).
