Housing Reform Model

1. Results 2. The data 3. The model

Lotline is a tool to help understand how much new housing specific housing reforms would add. It learns from places in the country where these reforms have passed, takes each state's housing market and local factors into account, and estimates what a reform would add over five years, as a range.

Results

The data

What the estimate is built on: which sources the state has, which the model used, and how complete they are.

The model

Predictions frozen before the outcomes could be seen, then scored against what happened.

Where these numbers come from

Every number on this page was computed by the Lotline engine and exported to a results bundle; the page only re-adds the engine's draws when a slider moves. Regenerate every bundle and this page with one command:

uv run lotline results --all
